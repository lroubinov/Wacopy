WACopy Connect for Windows 3.2.0
==========================

1. In WACopy, open /admin and create a private room.
2. Add a computer to that room and copy the one-time computer key.
3. Double-click Install.cmd on the Windows computer.
4. Enter https://wacopy.lroubinov.synology.me and the computer key.
5. When text, an image or a PDF arrives, focus the destination and press the configured shortcut.
6. If File Explorer is active, an image or PDF is saved in the open folder.
7. If a PDF arrives while Explorer is not active, it is saved in Downloads.

The paste shortcut can be changed from the tray icon under Settings.

The token is encrypted for the current Windows user. No inbound port is opened on Windows.
